# DavFXStudio portfolio

A responsive, single-page portfolio for David / DavFXStudio. Built with plain HTML, CSS, and JavaScript so new projects can be added by duplicating a `.project` link in `index.html` and changing its `data-category`, image, title, and description.

## Edit before launch

- Replace all concept project tiles and placeholder photography with David’s own work and project links.
- Update the contact email (`hello@davfxstudio.com`) to David’s preferred address.
- Add verified social profile links in the footer if desired.

The project tiles are explicitly identified as concepts/studies; no clients, awards, or results are claimed.

## GitHub Pages

The included workflow deploys the repository root on pushes to `main`. A repository owner/admin may need to select **Settings → Pages → Build and deployment → GitHub Actions** once before the workflow can publish.
